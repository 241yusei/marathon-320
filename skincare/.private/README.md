# .private/ — リポジトリに入らない置き場

このディレクトリは **`.gitignore` で除外**されている。ここに置いたものは
GitHub に push されず、公開サイトにも出ない。

## 何を置くか

- MARK-VU 診断書の **PDF 原本**（顔写真を含む）
- 経過観察の **顔写真**（`YYYY-MM-DD_front.jpg` / `_left45.jpg` / `_right45.jpg`）
- クリニックの施術記録・領収書・同意書

## なぜ分けるのか

このリポジトリは public で、`main` から GitHub Pages が配信されている。
一度 push した画像は履歴に残り、あとから削除しても
コミット履歴から復元できてしまう。顔写真は取り消しがきかない。

数値（毛穴 72、ブラウン色素 27 …）は本人の判断で公開する方針だが、
**顔写真と診断書原本は入れない**。これは技術的な制約ではなく設計上の線引き。

## 正本はどこにあるか

Google Drive の「320」フォルダ配下 `skincare/` に置く。
このディレクトリはあくまで作業用のローカル置き場で、
消えても Drive から復元できる状態を保つこと。

## 撮影前に必ずやること — 位置情報をオフにする

写真の EXIF には **GPS座標・端末名・撮影時刻**が記録される。
自宅で撮る以上、これは住所そのもの。

- iPhone: 設定 → プライバシーとセキュリティ → 位置情報サービス → **カメラ を「なし」**
- Android: カメラアプリの設定 → 位置情報タグ をオフ

「あとで剥がす」より、**撮影時に記録させない**ほうが確実。
一度でも位置情報つきの写真を共有すると、コピー先から回収できない。

## git に入れないための運用

`.gitignore` に入れてあるが、それだけに頼らない。

- **`git add -A` / `git add .` を使わない。** ファイルを個別に指定する
- 一度 push すると fork とキャッシュに残る。上流を消しても fork network から取得できる
- `git filter-repo` で消せるのは自分の履歴だけで、他人の clone は消せない

つまり **「入れてしまったら取り返せない」** ので、入れないことだけが対策になる。
