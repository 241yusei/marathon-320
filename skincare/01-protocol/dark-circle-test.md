# くまの型判定 — 手順と記録票

**所要5分。1回やれば当面やり直す必要はない。**

## なぜ先にやるのか

くまは3つの型があり、**型が違うと効くものが全く違う**。混合型が最も多い（ある研究で78%）。

| 型 | 正体 | 効くもの |
|---|---|---|
| **色素型**（茶） | メラニン。炎症後色素沈着を含む | ナイアシンアミド・ビタミンC・レチノイド・日焼け止め |
| **血管型**（青紫） | 皮膚が薄く、下の静脈が透ける | カフェイン外用・睡眠・鼻炎治療・鉄欠乏の是正 |
| **構造型**（影） | 眼窩下のくぼみ（tear trough）が落とす影 | **外用はほぼ無効**。ヒアルロン酸注入の適応 |

**構造型なのに美容液を半年塗り続ける**、が最も損な失敗。
逆に色素型なら外用で動く。だから先に切り分ける。

判定は4段階中いちばん重い「最重症」。切り分ける価値は大きい。

---

## 測定条件（これを守らないと判定がぶれる）

| 項目 | 条件 |
|---|---|
| 時間帯 | **朝と夜の2回**やる。血管型は疲労と夜間に濃くなるため、差自体が情報になる |
| 照明 | 天井の照明の**真下**。窓際の自然光は時間で変わるので使わない |
| 状態 | 洗顔後・ノーメイク・座位（立ちくらみ防止） |
| **左右** | **必ず左右を別々に判定する** |

> ★ あなたの場合、左右を分けることが特に重要。
> 診断書では **左目の下だけ**が赤み28（同年代平均5）・色ずれ15（4）・
> 表皮色素39（23）と突出していて、右目の下は全て平均以下だった。
> **左右で型が違う可能性がある。**

---

## テスト1: 牽引テスト — 色素型か血管型か

もっとも重要なテスト。

1. 鏡の前に座る
2. 人差し指を**頬骨の上**（目の下 2〜3cm）に置く
3. 皮膚を**下に、そして外側へ**、やさしく1〜2cm引っぱる
   - 強く引かない。伸ばすのではなく、たるみを取る程度
4. 引いた状態で色を見る
5. 指を離す
6. **反対側でも同じことをする**

| 結果 | 判定 |
|---|---|
| 引くと**色が薄くなる／消える** | **血管型**（皮膚が伸びて静脈が見えにくくなった） |
| 引いても**色がそのまま残る** | **色素型**（色は皮膚そのものにある） |
| 引くと**くぼみが目立たなくなる** | **構造型**の要素あり |

---

## テスト2: 角度テスト — 構造型かどうか

1. 天井の照明の真下に座る
2. **正面**から鏡を見る → 濃さを覚える
3. 顔を動かさず、**斜め45度**から見る（鏡を動かすか、横の鏡を使う）
4. さらに**下から**（顎を引いて上目づかい）見る

| 結果 | 判定 |
|---|---|
| **斜め45度で濃くなる** | **構造型**（影なので角度で変わる） |
| 角度を変えても濃さが同じ | 色素型・血管型（色なので角度で変わらない） |
| 上を向くと薄くなる | 構造型 |

---

## テスト3: 押圧テスト — 血管型の確認

1. 目の下を、**指の腹でゆっくり5秒押す**
2. 離した**直後**の色を見る

| 結果 | 判定 |
|---|---|
| 押している間に**白く抜ける**（退色する） | **血管型**（血液が押し出された） |
| 押しても色が変わらない | 色素型 |

透明なプラスチックの定規やスマホの画面を軽く押し当てると、
押している最中の色が見えるのでより分かりやすい。

---

## テスト4: 朝夜の差 — 血管型の裏取り

- **起床直後**と**就寝前**の2回、同じ照明で見る
- 睡眠不足の翌朝、飲酒した翌朝も見る

| 結果 | 判定 |
|---|---|
| 疲労時・夜に**濃くなる** | **血管型**の要素が強い |
| いつ見ても同じ | 色素型・構造型 |

---

## 記録票

日付: ____________　時間帯: 朝 / 夜

| テスト | 左目の下 | 右目の下 |
|---|---|---|
| 1. 引くと薄くなるか | 薄くなる / 変わらない | 薄くなる / 変わらない |
| 2. 斜め45度で濃くなるか | 濃くなる / 変わらない | 濃くなる / 変わらない |
| 3. 押すと白く抜けるか | 抜ける / 抜けない | 抜ける / 抜けない |
| 4. 夜のほうが濃いか | 濃い / 同じ | 濃い / 同じ |
| 色調の印象 | 茶 / 青紫 / 影 | 茶 / 青紫 / 影 |

**判定**

| 当てはまるもの | 型 |
|---|---|
| 1で薄くなる ＋ 3で白く抜ける ＋ 4で夜濃い | **血管型** |
| 1で変わらない ＋ 3で抜けない ＋ 色調が茶 | **色素型** |
| 2で斜めから濃くなる | **構造型** |
| 複数当てはまる | **混合型**（最も多い。主な型を1つ決める） |

## 型が決まったら

| 型 | 次にやること |
|---|---|
| **色素型** | numbuzin 5番を綿棒で目の下に薄く。日焼け止めを目の下まで塗る。8〜12週で判定 |
| **血管型** | カフェイン外用（The Ordinary Caffeine Solution 5%）。**それ以上に睡眠・鼻炎の治療・鉄欠乏の確認**。目をこすらない |
| **構造型** | **買わない。** 形成外科／美容皮膚科でtear troughのヒアルロン酸注入を相談（コホート150例超で6か月時97.6%が改善実感） |
| 混合型 | 主な型から着手。構造型が混ざっていれば、外用で全部は消えないと最初から織り込む |

## 左右で型が違った場合

片側だけ血管型・炎症型なら、**片側性の原因**を探す。

| 疑うもの | 確認方法 |
|---|---|
| 片側の擦り癖 | 無意識にどちら側の目をこすっているか、家族に聞く |
| 寝る向き | いつも同じ側を下にして寝ていないか。枕への接触 |
| 片側性のアレルギー性鼻炎 | 鼻づまりが片側に偏っていないか。耳鼻科 |
| 髭剃りの当て方 | ※目の下には髭が生えないので、この部位では該当しない |

**原因が特定できれば、外用より先にそこを直すほうが早い。**
