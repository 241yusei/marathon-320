# やらないこと と、他の柱との両立

---

## ⚠️ ランとの両立 — いま衝突している

**ポテンツァ後の禁忌と、ランニングの処方が正面から衝突している。**
これは Health OS が柱をまたいで見ないと気づけない種類の問題なので、先頭に置く。

| ポテンツァ後の禁忌 | 現在のラン処方 | 衝突 |
|---|---|---|
| 発汗・激しい運動を数日〜1週間避ける | 週3回のイージーラン | **する** |
| 熱（サウナ・熱いシャワー・長風呂）を2週間避ける | 運動後の入浴 | する |
| 直射日光・UV曝露を避ける（PIH体質のため特に） | 屋外ラン（7月は日中・夕方が中心） | **する** |
| 髭剃りを肌が落ち着くまで待つ | — | — |

### 結論：今週（第0期・〜8/18）は走らない

走力への影響は無視できる。第0期は7日で、Phase 0 の走行量は週6〜10km。
1週間走らないことによる有酸素能力の低下は測定できないレベルで、
筋メモリーも失われない。

一方、**この7日で色素沈着を作ると、それを消すのに3〜6か月かかる**。
時間あたりの損失は圧倒的に肌側が大きい。**トレードオフとして走りを止めるのが正しい。**

### 8/19以降のラン再開ルール

| 条件 | 内容 |
|---|---|
| 時間帯 | **日の出前か日没後**。UV量が最も少ない時間に走る |
| 日中に走るなら | 日焼け止め＋つばのある帽子。走行中の発汗で流れるので過信しない |
| 強度 | 現行どおり平均HR140以下。**発汗を最小にするという意味でも都合がよい** |
| 入浴 | 熱い風呂・サウナは施術後2週間（〜8/26）避ける。ぬるめのシャワーで |
| 走行後 | 汗を拭くのではなく**ぬるま湯で流す**。タオルで擦らない |

**副次的な発見**: 「全ランを平均HR140以下に抑える」という7/31からの処方は、
発汗量を減らすという意味でスキンケア側にも都合がよい。
2つの柱の制約がたまたま同じ方向を向いている。

## スキンケアでやらないこと

| ✗ | 理由 |
|---|---|
| **拭き取り（コットンで擦る）** | 物理摩擦→炎症→色素沈着。この体質で最も損な習慣 |
| **毛穴パック・角栓押し出し・剥がすタイプ** | 炎症・毛穴拡大・色素沈着 |
| **スクラブ・洗顔ブラシ** | バリア破壊・経表皮水分蒸散量の上昇 |
| **1日3回以上の洗顔** | 同上。**朝は水かぬるま湯だけで十分**（皮脂5＝平均以下） |
| **レチノイド＋酸＋高濃度ビタミンCの同日併用** | 刺激の掛け算→色素沈着を誘発 |
| **変性アルコールが上位配合の製品** | 韓国のサンスクリーン・トナーに多い。成分表の上位3〜5番目に Alcohol Denat. があれば避ける |
| **香料・精油・メントール配合品** | 赤み感受性が5段階中4番目。不要なリスク |
| **高濃度ナイアシンアミド（10%超）** | 4〜5%を超える上乗せデータが無い。刺激だけ増える |
| **PDRN／エクソソーム／グルタチオン外用に高い金を払う** | 経皮吸収の根拠が弱い（[04-evidence](../04-evidence/research.md) §訂正②） |
| **新製品を2つ同時に始める** | 何が合わなかったのか永久にわからなくなる |
| **BHAを毎日・全顔に使う** | 毛穴の原因が皮脂ではないので効かない。鼻だけ週1〜2回で足りる |

## 生活でやらないこと

| ✗ | 理由 |
|---|---|
| **目をこする** | くま・色素沈着の直接の悪化要因。花粉症・鼻炎があるなら**その治療自体がくま治療**になる |
| **サウナ・熱いシャワー・長風呂** | 熱は血管拡張＋色素の増悪因子。**特にポテンツァ後2週間** |
| **日焼け止めなしの外出** | 現在の最大の穴 |
| **睡眠不足** | バリア機能低下・くま悪化。ラン側の最優先事項とも一致 |

## 髭剃りでやらないこと

肌トーンが6段階で最も濃い側＝**偽性毛包炎（カミソリ負け）と色素沈着のハイリスク**。

| ✗ NG | ⭕ 正しい |
|---|---|
| 逆剃り（毛の流れに逆らう） | 毛の流れに沿って一方向 |
| ドライ剃り | 蒸しタオル→シェービング剤 |
| 多枚刃で深剃り | 電気シェーバー中心、またはカミソリなら単枚刃 |
| 肌を引っ張って剃る | 引っ張らない（皮膚の下で毛が切れて埋没する） |
| 同じ刃を使い続ける | こまめに交換 |
| 毎日ツルツルに剃る | 隔日／1〜2mm残すほうが予防に有利 |
| 剃った直後にアルコール系アフターシェーブ | 無香料保湿 → 日焼け止め |

**ポテンツァ後は、剃るのも肌が落ち着くまで待つ。**

## 第0期（〜2026-08-18）に限って禁止するもの

| 対象 | 期間 |
|---|---|
| レチノイド（RoC含む） | 5〜7日（処方薬なら最大2週間） |
| AHA/BHA/酸（goodalパッド含む） | 5〜7日 |
| 高濃度ビタミンC | 3〜5日 |
| 拭き取り・スクラブ | 7日 |
| メイク | 24〜48時間 |
| 熱・発汗（サウナ・激運動・熱い風呂） | 数日〜1週間 |
| 直射日光 | 最重要 |
| 皮むけをむしる | 絶対。色素脱失／沈着の原因 |
| 飲酒・喫煙 | 48〜72時間 |
| 髭剃り | 肌が落ち着くまで |

**施術したクリニックの指示が常に優先。** ここに書いた「5〜7日」は
複数のクリニックのアフターケアガイドに共通する一般的な見解であって、
施術強度による個別調整が要る。
