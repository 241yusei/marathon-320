## 0. 「攻める」の定義を先に決める

**この肌で「強い成分を早く入れる」のは攻めではなく自滅。**
皮膚トーンタイプが6段階で最も濃い側＝炎症後色素沈着（PIH）のハイリスク。
刺激を与えるとそれ自体が新しいシミになり、消すのに3〜6か月かかる。

だから攻める軸を3つに定義し直す。

| 軸 | 内容 | 攻めてよい理由 |
|---|---|---|
| **① 光防御を上限まで** | UVだけでなく**可視光**まで止める | 副作用がない。やりすぎという概念がない |
| **② 有効成分を全部載せる（順序を守って）** | 6か月でナイアシンアミド・VC・レチノイド・アゼライン酸を全部載せる | 順序と間隔を守れば全部載る。焦らないことが最短 |
| **③ 内側から攻める** | 外用の限界を内服が超える領域がある | 経口トラネキサム酸は外用より効果量が大きい |

**攻めの本質は「順序の最適化」。** 6か月で全部載せる前提で、
どれを何週目に入れるかを設計する。

| | オバジC デイセラムUV（現行） | **Obagi Sun Shield Tint SPF50** |

アドヒアランス研究で最も効く介入は工程の簡素化（配合1剤で1日1回88% vs 別々61%）なので、
**1本で可視光もビタミンCも兼ねるこの製品が、この肌にとって最適解**。

- 米国 Obagi Medical 製。国内流通のオバジ（ロート）とは別ライン＝**輸入が必要**

### 届くまでの間

**オバジC デイセラムUV を毎朝0.8g で続ける。**
「最適な1本が届くまで塗らない」が最悪の選択。UV防御は十分にある。

## 4. 夜のルーティン（完成形へ向けた段階導入）

### 洗顔・クレンジング — ここが一番やりがちな失敗

**原則: 1回。ダブル洗顔をしない。**

| 判断 | 根拠 |
|---|---|
| **ダブル洗顔は原則しない** | 乾燥・敏感肌では過剰洗浄がセラミドと天然保湿因子を奪い、乾燥と刺激を招く。Tゾーンが乾燥しており、ポルフィリン1（平均3）で詰まりもない |
| **アルカリ石鹸を使わない。シンデット（弱酸性〜中性の合成界面活性剤）を選ぶ** | アルカリ石鹸は TEWL（経表皮水分蒸散量）と紅斑指数を上げる。皮膚表面の弱酸性を保つことが角層バリアの維持に重要 |
| **例外: アネッサを使った日だけ2段階** | 高耐水性は落ちにくい。落とすためにゴシゴシするほうが有害なので、その日はオイルかバームで先に浮かせる |

**やり方（摩擦をゼロに近づける）**

1. 手を洗う
2. クレンザーを顔にのせ、**30秒そのまま置く**（先に溶かす。こすらない）
3. **指の腹**でやさしく円を描く。**コットン・クロス・洗顔ブラシは使わない**（摩擦が色素沈着の原因）
4. ぬるま湯（熱くしない）で流す
5. タオルは**押さえるだけ**。擦らない

**製品**: Round Lab 1025 独島クレンザー ／ Illiyoon セラミドアト弱酸性フォーム ／
Isntree ヤマイモ ヴィーガンミルククレンザー（いずれも弱酸性・低刺激）

### 夜の有効成分 — 曜日で分ける

**完成形（2026年11月頃）**

| 曜日 | 内容 |
|---|---|
| **レチノイドの日（週3〜4）** | 洗顔 → 保湿を薄く → **レチナール** → 保湿を重ねる（サンドイッチ法） |
| **それ以外の日** | 洗顔 → **ナイアシンアミド5%** → Torriden → 保湿 |
| 頬の色素部位のみ（任意） | アゼライン酸10% または Thiamidol を部分使い |

**レチノイドとビタミンCを同じ夜に重ねない。** 朝＝VC（日焼け止めで兼用）、夜＝レチノイド。
**レチノイドと酸を同じ日に使わない。**

## 5. 導入スケジュール（6か月・全部載せる前提）

**ルール: 新規は2週間に1つ。刺激が出たら1段戻して4週間待つ。**

| 予定日 | 追加 | 使い方 | 目的 |
|---|---|---|---|
| **2026-08-14（済）** | 手持ち日焼け止めを毎朝0.8g | 朝 | 実施率の確立 |
| 2026-08-16 | ラン再開（日没後） | — | 肌との両立 |
| **2026-09-02** | **ナイアシンアミド5%** | 夜のみ | 色素・毛穴・バリア。最も安全で最もエビデンスがある一手 |
| 2026-09-09 | ナイアシンアミドを朝夜へ | 朝夜 | — |
| **2026-09-16** | **酸化鉄SPFに差し替え** | 朝 | **可視光防御。最大のROI** |
| **2026-09-30** | **レチナール 0.03%** | 夜・**週2から** | 毛穴＋色素。効果は最大だが刺激も最大 |
| 2026-10-14 | レチナールを週3〜4へ | 夜 | — |
| **2026-10-28** | アゼライン酸10% or Thiamidol | 頬の色素部位のみ | 色素の上積み |
| **2026-11-11** | **MARK-VU 再測定①** | — | 効果判定・分岐 |
| 2026-12〜 | 判定に応じて濃度を上げる／クリニックへ | — | — |
| **2027-02-10** | **MARK-VU 再測定②** | — | セルフケア継続かクリニック復帰か |

**この順序である理由**

1. **光防御が先**。他を全部やっても、可視光で作られる色素に打ち消される
2. **ナイアシンアミドが2番目**。刺激が最も低く、バリアを強くする。
   後から入れるレチノイドの刺激耐性を上げる下地になる
3. **レチノイドが最後**。効果は最大だが刺激も最大。バリアが整ってから入れる
4. **アゼライン酸は全顔でなく部位限定**。総量を増やさず狙い撃つ

## 6. インナーケア（内服）

外用より内服のほうが効果量が大きい領域がある。ただし**適応の確認が先**。

| 手段 | 強さ | 内容 | 判断 |
|---|---|---|---|
| **経口トラネキサム酸** | **[A]** | ネットワークメタ解析で最適用量は **750mg/日×12週**。MASI の標準化平均差 2.46。効果量は **内服 ＞ 注射 ＞ 外用** | **★肝斑の診断が先。§6-1** |
| **Polypodium leucotomos（PLE）** | **[B]** | シダ抽出物の経口光防御。JAMA Dermatol の RCT で日焼け止めの補助として肝斑に有効。**アジア人での二重盲検プラセボ対照試験**あり。8週で最小紅斑量が上昇し紅斑が減少 | **屋外ランナーには合理的。§6-2** |
| L-システイン＋VC（ハイチオールC等） | [C] | チロシナーゼ抑制＋ターンオーバー促進。一般用医薬品レベル | 補助。害は少ないが期待しすぎない |
| **鉄** | — | 鉄欠乏はくま（血管型）の悪化因子。**かつ持久系のパフォーマンスに直結** | **★血液検査で確認する価値が最も高い。§6-3** |
| ビタミンD | — | 一般的な不足が多い | 血液検査のついでに |
| 経口ニコチンアミド | [A] | ONTRAC 試験で非黒色腫皮膚がんを12か月で23%減。**ただし美白のエビデンスではない** | 低リスクなので不要 |
| 経口コラーゲンペプチド | [C] | 2025年の23RCTメタ解析で、非企業資金・高品質研究に限ると**有意差が消失** | 不要 |

### 6-1. 経口トラネキサム酸 — 効果は最大だが、まず診断

**エビデンスは内服が最も強い。** ただし**すべて肝斑（melasma）を対象にした研究**で、
本人は肝斑と診断されていない。

**肝斑を疑う根拠はある**: ブラウン色素が右頬37・左頬36と**両頬対称に高い**。
これは肝斑の典型的な分布。ただし30歳男性で肝斑は相対的に少なく（男性は肝斑症例の約1割）、
屋外ランによる日光性色素斑の可能性も同等以上にある。

| | |
|---|---|
| **やること** | **皮膚科を受診して肝斑かどうかの診断を受ける** |
| 肝斑だった場合 | 経口TXA 750mg/日×12週。国内OTCの**トランシーノII**が同用量（TXA 750mg＋L-システイン＋VC＋B6）。臨床試験で8週の改善率60.4%（4週時点は19.0%） |
| 肝斑でなかった場合 | 外用先行。TXA内服のエビデンスは直接は当てはまらない |
| **★必ず医師に伝えること** | **マラソンをしていること。** TXAは抗線溶薬で、長距離走による脱水と併せた血栓リスクを問診してもらう必要がある。血栓の既往・家族歴も申告する |

**自己判断で始めない。** ここだけは診断を挟む。

### 6-2. Polypodium leucotomos — 屋外ランナーには合理的

**日焼け止めの代替ではなく補助。** 「塗り直しができない状況」を内側から補う位置づけ。

- JAMA Dermatology の RCT で、日焼け止めへの追加として肝斑に有効
- アジア人での二重盲検プラセボ対照試験あり
- 8週間の摂取で最小紅斑量（MED）が上昇し、UVB紅斑が減少

**8月に屋外を走る／塗り直しが現実的でない場面がある**という本人の条件に、
この作用機序は噛み合う。国内では Heliocare 等が輸入で入手可能。

**位置づけは「あれば良い」。** 日焼け止めを塗らずにこれで済ませるのは本末転倒。

### 6-3. ★ 血液検査 — 柱をまたいで最も費用対効果が高い

**鉄欠乏は「くま」と「ランのパフォーマンス」の両方の悪化因子。**
1回の採血で両方の柱に答えが出る。

| 項目 | なぜ |
|---|---|
| **フェリチン・ヘモグロビン** | 鉄欠乏はくま（血管型）を悪化させ、持久系のパフォーマンスを直接落とす。**持久系アスリートは鉄欠乏の頻度が高い** |
| ビタミンD | 骨・免疫。ランナーの疲労骨折予防にも |
| 肝機能・凝固系 | 経口TXAを検討するなら必須 |

このプロジェクトの `streams.js` では血液データが「一度も受領していません」の状態で、
鉄・ビタミンDのサプリ推奨が**構造的にブロックされている**。
検査を受ければそのブロックが外れる。

**健康診断でも大半はカバーできる。** フェリチンは項目に無いことが多いので追加を頼む。

### まとめ — インナーケアの優先順位

| 順 | やること | いつ |
|---|---|---|
| **1** | **血液検査**（フェリチン・ヘモグロビン・ビタミンD） | 今月中 |
| **2** | **皮膚科で肝斑かどうかの診断** | 今月〜来月 |
| 3 | 肝斑なら経口TXA（医師の判断で） | 診断後 |
| 4 | PLE（任意・屋外が多い時期に） | いつでも |
| — | コラーゲン・ニコチンアミド内服 | **不要** |

## 9. この計画で「起きること」の時間割

| 時期 | 起きること |
|---|---|
| 〜1か月 | **何も見えない。** 習慣が立ち上がるだけ |
| 2〜3か月 | ナイアシンアミドで色ムラがわずかに動く（4〜8週） |
| 3か月（11/11） | 再測定①。色素が動き始める帯。毛穴はまだ |
| 4〜6か月 | レチノイドの初期変化（2〜4か月）。毛穴の見た目が動き始める |
| 6か月（2027-02-10） | 再測定②。**レチノイドの本判定**。ここが最初のまともな評価点 |
| 8〜12か月 | レチノイドの最大効果 |

**この計画は6か月で判定するもの**であって、1か月で結果を見るものではない。
途中でやめないことが、どの成分を選ぶかより効く。
