# 毎日の手順 — いつ・どこで・何を

**現在のフェーズによって中身が変わる。** いまどのフェーズかは
[schedule.md](schedule.md) のフェーズ表で確認すること。

以下は **第2期以降（維持期）の完成形**。第0期・第1期はもっと少ない（後半に記載）。

---

## 朝 — 起床後、洗面所

| 順 | やること | 場所・タイミング | 所要 |
|---|---|---|---|
| 1 | **ぬるま湯で洗うだけ**（洗顔料は使わない） | 洗面所・起床直後 | 30秒 |
| 2 | ビタミンC美容液 2〜3滴 | 同上 | 20秒 |
| 3 | Torriden DIVE IN セラム | 同上 | 20秒 |
| 4 | 保湿クリーム 少量 | 同上 | 20秒 |
| 5 | **日焼け止め 0.8〜1g（2本指）** | 同上・外出の20分前 | 30秒 |

**朝に洗顔料を使わない理由**: 皮脂の測定値が5（同年代平均7）で平均以下。
洗いすぎはバリアを削るだけで、毛穴には効かない。

**2本指ルール**: 人差し指と中指の、第一関節までの長さ2本分。これで約0.8〜1g。
これより少ないと、表示されているSPFの半分以下しか得られない。

### 撮影の仕様 — ここを外すと比較不能になる

| 項目 | 仕様 | 理由 |
|---|---|---|
| **レンズ** | スマホの**望遠側**（90〜105mm相当）を使い、距離を取る | 標準・広角（50〜55mm相当）は顔の中央が歪む。見ているのが肌の変化ではなくレンズ由来の変形になる |
| **照明** | リングライトなどの**拡散光**。自然光は使わない | 時刻・天候で色温度が変わり、色素の比較が壊れる |
| **位置** | 三脚＋**床にテープでマーカー**。毎回同じ位置に立つ | 再現性を記憶に頼らない |
| **角度** | レンズ面を顔に対して垂直。正面／左45°／右45° の3枚だけ | 数度ずれるだけで陰影とシワの見え方が変わる |
| **背景** | 無反射・単色を常設 | |
| **前処置** | 洗顔後30分・メイクなし・同じ時間帯 | |

**まず撮影場所を1か所決めて、床にテープを貼るところから始める。**
これをやらないと、半年後に並べたときに「改善したのか撮り方が変わったのか」が
永久に判別できない。条件が崩れた回のデータは比較から外す。

**頻度は4週間隔で足りる。** 毎日撮ると日々のむくみ・照明のノイズに埋もれて
かえって判定が悪くなる。表皮のターンオーバーが40〜56日なので、4週はその半分にあたる。

**撮影前に位置情報をオフにする**（[../.private/README.md](../.private/README.md)）。

## 髭剃り — 隔日、入浴後

肌トーンが6段階で最も濃い側＝**PFB（偽性毛包炎／カミソリ負け）と
炎症後色素沈着のハイリスク**。左頬の赤みが局所的に高い（28、全体平均は6）のは
剃り方が関係している可能性がある。

| 順 | やること |
|---|---|
| 1 | 蒸しタオルで髭を柔らかくする |
| 2 | シェービング剤をつける（ドライ剃り禁止） |
| 3 | **毛の流れに沿って一方向**に剃る。逆剃りしない |
| 4 | 肌を引っ張らない（皮膚の下で毛が切れて埋没する） |
| 5 | 剃ったあとは無香料保湿 → 日焼け止め |

- **電気シェーバー中心**。カミソリなら単枚刃で、刃はこまめに交換
- **毎日ツルツルに剃らない。** 隔日・1〜2mm残すほうが埋没毛の予防に有利
- アルコール系アフターシェーブは使わない

## 第0期（施術当日〜7日）の手順 — 守りに徹する

この時期の目的は治すことではなく、**邪魔をしないこと**。

**朝**: ぬるま湯 → Torriden → 保湿（セラミド or ヒルドイド） → （2日目以降）ミネラル日焼け止め
**夜**: 超低刺激クレンザーで1回 → Torriden → 保湿

これだけ。他は何も足さない。

---

## 第1期（8日目〜4週）の手順 — 日焼け止めを習慣にする

**この期間の目標は「日焼け止めを毎日塗る習慣をつくる」ことだけ。**

**朝**: ぬるま湯 → （2週目以降ナイアシンアミド） → 保湿 → **日焼け止め 2本指**
**夜**: 低刺激洗顔 → （2週目以降ナイアシンアミド） → Torriden → 保湿

焦って複数の美容液を同時に入れないこと。何が合わなかったのか永久にわからなくなる。
