# 03-log — 記録のつけ方

**月ごとに1ファイル**（`YYYY-MM.md`）。**追記のみ**で、過去の月のファイルは編集しない。

## なぜ記録するのか — 測定器ではなく行動介入として

自己申告の使用率は実測の約2倍を報告する（ログ80〜90%に対し隠れ電子モニタでの実測は約40%。
Krejci-Manwaring 2007）。だから **ここに書いた「やった」の数を継続率として信用してはいけない。**

それでも記録する理由は、**記録・観察されている状態そのものが継続率を押し上げる**から
（Hawthorne効果。通知＋実測連動アプリで4週時 65% vs 38%, P=0.004／Svendsen 2018）。
通知単独では効かず、通知＋記録では効いた、という対比が示すのは、
効いているのが「思い出させること」ではなく「見られていること」の側だということ。

つまりこのファイルの目的は **自己観察の可視化**であって、正確な統計ではない。
書き漏らしを気にしなくてよい。書くこと自体に意味がある。

## 何を書くか

**毎週1行**（日曜の夜）で足りる。義務にしない。

```
## 2026-08-18（火）
- 日焼け止め: 塗った（外出2h）
- 刺激: なし
- メモ: 施術部位の赤みが引いてきた
```

**刺激・赤み・皮むけが出た日は必ず書く。** 何を入れた翌日かを特定できないと、
原因の切り分けが永久にできなくなる。これがこのファイルの最重要用途。

## 特に記録する価値があるもの

| 項目 | なぜ |
|---|---|
| 新製品を入れた日 | 反応が出たときに帰属できる。ROATでは陽性の全例が10日以内に出る |
| 刺激・赤み・皮むけが出た日 | 上と対にして原因を特定する |
| **日焼け止めを塗らなかった日** | 塗った日より、塗らなかった日を数えるほうが実態に近い |
| 髭剃りをした日 | 左目の下以外の赤みとの関連を見る |
| 睡眠不足・鼻炎の悪化 | くまの変動要因 |

## 日焼け止めの実施率だけは別に見る

日焼け止めは効果判定の対象にならない（効果が数字で出るまで年単位。Hughes 2013 の4.5年RCT）。
なので **実施率だけで管理する**。最も正直な指標は自己申告ではなくこれ:

> **1本を何日で使い切ったか。**
> 50ml を毎日0.8g使えば **約60日で1本**。半年で1本しか減っていないなら、量が全く足りていない。

開封日を製品に直接書いておくこと。
