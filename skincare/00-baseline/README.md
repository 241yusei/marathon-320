# 00-baseline — 測定と診断の記録

**このフォルダのファイルは書き換えない。** 再測定のたびに新しいファイルを追加する。

```
YYYY-MM-DD_markvu.md     MARK-VU 診断
YYYY-MM-DD_derm.md       皮膚科の受診記録（あれば）
```

誤りが見つかった場合も、元の記述は消さずに末尾へ
「## 訂正 YYYY-MM-DD（理由）」の節を足す。これは医療記録の実務と同じ考え方で、
「当時どう記録されていたか」自体が情報だから。

## 測定項目の見かた

| 項目 | 何を測っているか | 高いと |
|---|---|---|
| 毛穴 | 毛穴の面積・深さ | 悪い |
| シワ／未来シワ | 現在のシワ／将来できやすさ | 悪い |
| 表皮層色素沈着 | 表皮のシミ | 悪い |
| メラニン | メラニン量（UV撮影） | 悪い |
| ブラウン色素 | 茶色系の色素 | 悪い |
| 赤み | 毛細血管拡張・炎症 | 悪い |
| 肌の色ずれ | 色の**ムラ**（量ではなく分布） | 悪い |
| ポルフィリン | アクネ菌の代謝産物の蛍光 | 悪い |
| 皮脂 | 皮脂分泌量 | 部位による |
| **光彩面積** | 肌表面の滑らかな面積＝きめ | **良い**（唯一の逆向き） |

部位記号: **A**=額 / **B**=鼻 / **C·D**=右·左目尻 / **E·F**=右·左目の下 /
**G·H**=右·左頬 / **I·J**=右·左ほうれい線

## 再測定のときに気をつけること

- **洗顔から30分以上あける**（初回は水分が全ゾーン none ＝測定不良だった）
- 室温で安定させてから測る
- 同じ機器・同じ施設で測る。機器が変わると数値の互換性がない
- 総合値だけでなく**部位別を必ず控える**。初回は総合値では平均並みだったメラニンが、
  部位別では頬39（平均30）／額16（平均27）と正反対だった
