### 判定の理由

| 製品 | 理由 |
|---|---|
| **Torriden DIVE IN** | 5D低分子ヒアルロン酸・パンテノール・マデカソシド・セラミドNP・**無香料**。刺激要因が少なく、施術翌日から使えるレベル |
| **オバジC デイセラムUV** | SPF50+ PA++++。**酸化鉄なし＝可視光は素通り**。ただしVC誘導体3種＋トコフェロール入りで、朝のビタミンCを兼ねられる。UV防御としては十分 |
| **アネッサ** | 耐水性が最大の強み。ただし**エタノールが上位4番目**なので、赤み感受性4/5には常用より汗の日専用が妥当。酸化鉄なし |
| **ROUND LAB 1025 独島** | 酸化亜鉛＋酸化チタン。低刺激で無難。酸化鉄なし |
| **ヒルドイド** | バリア改善のエビデンスあり。ただし本来の適応は乾燥性皮膚疾患で、**乾燥のない顔全体への常用は適応外**。セラミドクリームに任せる |
| **ヘパリン類似ローション** | ヒルドイドと同一成分。両方は不要 |
| **goodal パッド** | 酸（AHA/PHA/LHA）× 物理摩擦（拭き取り）× 香料の**三重刺激**。しかも毛穴が詰まっていない（ポルフィリン1・皮脂5）ので角質ケアの必要性が薄い |
| **RoC** | レチノール自体は正しい。問題は**グリコール酸と香料の同梱**。さらにシワは同年代平均より良い（10 vs 17）ので攻めた処方が不要 |

### ★ 日焼け止め3本の共通の弱点

**3本とも酸化鉄なし＝可視光（HEV）防御はゼロ。**
UVは止まっているが、肌トーンが濃いほど可視光でも色素沈着が起きる。
ここが最大かつ唯一の穴。

## C. 買わないもの

| ✗ | 理由 |
|---|---|
| PDRN／ポリヌクレオチド外用 | 500ダルトン則により経皮到達が疑わしい [D] |
| エクソソーム外用 | 同上 |
| グルタチオン外用 | 経皮吸収の根拠が弱い。100ppmは論外 |
| 高濃度ナイアシンアミド（10〜20%） | 4〜5%を超える上乗せデータなし、刺激だけ増える |
| 拭き取りパッド全般 | 摩擦が色素沈着リスク |
| 馬油・スネイル・発酵系 | 保湿としては可。色素・毛穴への根拠は [D] |
| BHAの毎日・全顔使用 | 毛穴の原因が皮脂ではないので効かない。鼻だけ週1〜2回で足りる |
| 高濃度ビタミンC（COSRX 23%等）を今すぐ | 第2期後半まで待つ。日焼け止め側のVC誘導体で当面足りる |
| 経口コラーゲンペプチド | 高品質研究に限ると有意差が消失 |
| 経口ニコチンアミド | 皮膚がん予防のエビデンスであって美白ではない |
| アルカリ石鹸 | TEWL と紅斑指数を上げる |

## D. 成分表の確認方法

### 酸化鉄が入っているか

> **酸化鉄** ／ **Iron Oxides** ／ **CI 77491**（赤）**CI 77492**（黄）**CI 77499**（黒）

無ければ、どれだけ高SPFでも可視光は防げない。
あっても濃度は分からない（97.3%の製品が非開示、目標は約3〜3.5%）ので、
**色の濃さだけが手がかり**になる。

### 避ける成分

| 成分 | なぜ |
|---|---|
| **Alcohol Denat.（変性アルコール）が上位3〜5番目** | 赤み感受性4/5には不要なリスク。韓国のトナー・サンスクリーンに多い |
| 香料・精油・メントール | 同上 |
| グリコール酸などの酸 × レチノイド の同梱 | 刺激の掛け算 |
