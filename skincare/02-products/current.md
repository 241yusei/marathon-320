### なぜ goodal と RoC を外すのか

**goodal**: 酸 × 物理摩擦（拭き取り）× 香料の三重刺激。
色素沈着ハイリスク体質＋赤み感受性4/5の肌に毎日この組み合わせを与えるのは、
色素を作りに行っているのと同じ。しかも毛穴が詰まっていないので角質ケアの必要性が薄い。
どうしても使うなら「顔に10分置くパックとして週1〜2回」に限定する。

**RoC**: レチノール自体は正しい選択。問題は**グリコール酸（AHA）と香料が同梱**されていること。
さらにシワは同年代平均より良い（10 vs 17）ので、ディープリンクル用の攻めた処方は不要。

## 買わなくていいもの

| ✗ | 理由 |
|---|---|
| PDRN／ポリヌクレオチド外用 | 500ダルトン則により経皮到達が疑わしい[D] |
| エクソソーム外用 | 同上 |
| グルタチオン外用 | 経皮吸収の根拠が弱い。100ppmは論外 |
| 高濃度ナイアシンアミド（10〜20%） | 4〜5%を超える上乗せデータなし、刺激だけ増える |
| 馬油・スネイル・発酵系 | 保湿としては可。色素・毛穴への根拠は[D] |
| 拭き取りパッド全般 | 摩擦が色素沈着リスク |
| BHAの毎日・全顔使用 | 毛穴の原因が皮脂ではないので効かない |
