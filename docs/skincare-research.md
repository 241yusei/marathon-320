## 1. 光防御 — 最大のROI

| 手段 | 強さ | 内容 |
|---|---|---|
| 酸化鉄配合の色つき日焼け止め | **[A]** | 可視光（HEV）は Opsin3 経由で Fitzpatrick III 以上に色素沈着を誘導。酸化鉄配合の色つきは無色SPF50+より色素沈着を有意に抑制。UV+可視光防御はUV単独よりMASI改善が大きい（75% vs 60%, P<0.001） |
| 塗布量 2mg/cm² | **[A]** | 顔で約0.8〜1g（2本指ルール）。実使用は半量以下が大半で、表示SPFの約50%しか得られていない |
| 塗り直し | [B] | 2〜3時間ごと、発汗後 |

**濃いシェードほど可視光を止める。** Beauty of Joseon のティンテッドは公表データで
シェード別のブルーライト遮断率が LP100（最も明るい）57.8% → MY220 83.1% → DN350 87.0%。
肌トーンが最も濃い側なら、**自分に合う中〜濃色シェードを選ぶこと自体が色素対策**になる。
「白くしたいから明るいシェード」は目的に対して逆効果。

**注意**: 電子機器のHEV照度は太陽光の1/100〜1/1000で、色素を悪化させるには不十分との
指摘がある。本命は屋外のUV・可視光対策。

### ★ 日焼け止めは「効果判定」の対象にしない

Hughes 2013（Ann Intern Med、n=903、**4.5年**RCT）で、毎日使用群は皮膚老化の進行が
検出されず、随時使用群より24%少なかった（相対オッズ0.76、95%CI 0.59-0.98）。

つまり **効果が数字で見えるまで年単位かかる**。「変化がないこと」が成果である介入なので、
写真での短期判定は原理的に不可能。**実施率（塗った日の割合）だけで管理する。**

## 2. 毛穴

| 手段 | 強さ | 実態 |
|---|---|---|
| **RFマイクロニードリング（ポテンツァ）** | **[B]** | 組織学的に毛穴径が平均41.7%縮小（64.98→37.86μm）、皮脂腺縮小・真皮コラーゲン増生。中国人コホート22例×3回で毛穴スコア3.55→2.59。**1回より複数回（1〜3か月間隔）** |
| **レチノイド外用** | **[A]** | タザロテン0.1%の24週RCT（568例、JAAD）で毛穴の見た目・小じわ・色素斑が有意改善。レチノール0.2%で毛穴拡張30.6%減、トレチノイン0.025%で37.5%減 |
| ナイアシンアミド4% | [B] | 8週で毛穴・肌ムラ改善（split-face RCT） |
| BHA/サリチル酸 | [C] | 角栓には有効。**毛穴サイズ自体への強いRCTはない** |
| 毛穴パック・押し出し | ✗ | 炎症→色素沈着→むしろ悪化 |

**決定因子**は皮脂分泌量・毛包径・毛包周囲の真皮弾性線維の減少・光老化。
外用は「見た目」を改善するが、拡大した開口部を恒久的に小さくはしない。

**本人への適用**: ポルフィリン1（平均3）・皮脂5（平均7）と低い＝詰まりが原因ではない。
**BHAに期待しない。** 毛穴の主力は「ポテンツァ（構造）＋レチノイド（外用）＋光防御（悪化予防）」。

## 3. 色素沈着

### 3-1. 効くもの

| 成分 | 強さ | 実態 |
|---|---|---|
| **ナイアシンアミド 4〜5%** | **[A]** | メラノソーム転送阻害＋バリア改善。Bissett 2004（n=50、12週、split-face）で色素斑・黄ぐすみ・赤み・キメが有意改善 |
| **ビタミンC（純アスコルビン酸）** | **[A]** | チロシナーゼ抑制＋抗酸化。高濃度は刺激・酸化が課題 |
| **レチノイド** | **[A]** | ターンオーバー促進で炎症後色素沈着を改善。skin of color でも複数試験。アダパレン0.1%は刺激が少なく約66%で改善（南アフリカのオープン試験） |
| Thiamidol 0.2% | [B] | ヒトチロシナーゼ最強阻害剤（IC50≈1.1µmol/L）。Lima 2021（JEADV、90日RCT）でmMASI 43%減、4%ハイドロキノン（33%減）と非劣性 |
| アゼライン酸10〜20% | [B] | チロシナーゼ阻害＋抗炎症。過活動メラノサイトを選択的に抑制 |
| ビタミンC誘導体 | [B] | 安定だが純VCほどのデータ量はない |
| アルブチン | [B] | 韓国の美白告示成分。穏やか |

### 3-2. ★訂正: トラネキサム酸「外用」は思われているほど強くない

一般に「トラネキサム酸＝美白の切り札」と語られるが、
2026年 Dermatologic Therapy のシステマティックレビューは、
**外用3%・5%を12週間使った試験では肝斑への臨床的有効性が示されなかった**と明記している。
2024年のメタ解析（22研究・1,280名）でも効果量は **内服 ＞ 注射 ＞ 外用** の順。

→ **[C]**。含まれていて損はないが、これ1本に賭けるべき成分ではない。

### 3-3. ★訂正: PDRN・グルタチオン外用・エクソソームは金を払う価値が薄い

Dermatology Times（2026年8月）の検証記事は、PDRN について
**角層の「500ダルトン則」からして通常の外用で真皮に届くのは物理的に考えにくい**と指摘。
注射（スキンブースター）のエビデンスは split-face RCT レベルで存在するが、
**塗るPDRNの効果は同じ処方に入っている保湿剤・バリア成分によるものである可能性が高い**。

グルタチオン外用も同様。人気製品に入っているのは100ppm（＝0.01%）で、
効果を期待できる量ではない。 → **[D]**

### 3-4. ★訂正: ナイアシンアミドは高濃度ほど良いわけではない

エビデンスの中心は **4〜5%**（Bissett 2004/2005）。皮脂抑制のデータは2%で既に頑健で、
それ以上増やしても上乗せは記録されていない。逆に円板状エリテマトーデスのRCTでは
**4%は2%より刺激発生率が高かった**。

→ 赤み感受性が5段階中4番目の本人には **5%前後が最適解**。20%は刺激とコストの無駄。

## 4. 目のくま — 型を見分けないと何を買っても無駄

混合型が最多（ある研究で78%）。

| 型 | 見分け方 | 効くもの |
|---|---|---|
| 色素型（茶） | 皮膚を軽く引っ張っても色が残る | ナイアシンアミド、ビタミンC、レチノイド（低頻度）、日焼け止め |
| 血管型（青紫） | 引っ張ると薄くなる／横になると軽減 | カフェイン外用[B]、睡眠、鼻炎治療、鉄欠乏是正 |
| 構造型（影） | 正面より斜め45度から見ると濃い | **外用はほぼ無効**。ヒアルロン酸注入（コホート>150例で6か月時97.6%が改善実感） |

**自宅で30秒の判定法**
1. 鏡の前で下まぶたを指で軽く外側に引く → 色が薄くなれば**血管型**、残れば**色素型**
2. 天井のライトの真下で正面／斜め45度から見る → 斜めで濃くなれば**構造型**

**本人への適用**: 部位別データで左目の下だけが
赤み28（平均5）・色ずれ15（平均4）・表皮色素39（平均23）と突出し、右目下は全て平均以下。
**左右非対称**なので、片側性の要因（擦り癖・寝る向き・片側性鼻炎による静脈うっ滞）を先に疑う。
構造型が主体なら、6か月セルフケアで反応がなくても落胆せず注入相談へ切り替えるのが最短。

## 6. 効果判定に必要な期間 — 成分ごとに違う

### ★ 表皮ターンオーバーは28日ではなく40〜56日

俗に言う「28日周期」は誤り。Halprin（Br J Dermatol 1972）が Weinstein のデータを
再検証して47〜48日と算出、剥離速度モデルでは前腕で約45日。角層単独では14〜20日。

→ **効果判定の最小単位は4週ではなく8週。** 28日で「効かない」と判定すると、
まだ入れ替わっていない表皮を見て切り捨てることになる。

| 対象 | 判定できるようになる時期 | 出典 |
|---|---|---|
| 刺激・アレルギーの帰属 | **10〜15日** | ROAT: 陽性の中央値3日、全陽性例が10日以内（Amsler 2022）。ESCD は約15日を推奨 |
| ナイアシンアミドの色素・キメ | **4〜8週** | Hakozaki 2002（日本人女性18名、split-face、二重盲検、8週） |
| 色素（ハイドロキノン系） | **8〜12週** | week8 P=.002、week12 P=.012 |
| ざ瘡 | **12週** | FDA の規制標準。これ未満で「効かない」と判定しない |
| レチノイドの光老化（シワ・斑） | **2〜4か月で初期変化、判定は6か月、最大効果8〜12か月** | Olsen 1997（48週、多施設二重盲検） |
| ビタミンCのシワ | 12週 | 色素の明色化はさらに長い（Correia 2023 系統的レビュー） |
| 日焼け止め | **判定対象にしない** | 4.5年RCTでようやく24%差（Hughes 2013） |

### 炎症後色素沈着は表皮型と真皮型で桁が違う

- **表皮型**: 数週〜数か月。無治療でも6〜12か月で消退しうる
- **真皮型**: メラニンが真皮のマクロファージに取り込まれるため**年単位**。半永久的になることも

→ 12週で動かない色素を「失敗」と読むと誤る。真皮性が混ざっている場合、
外用の評価期間内に動かないのは想定内。判定対象から外すか別軸で扱う。

### ★「新規成分は2週間あけて1つずつ」の根拠

**この間隔そのものを直接検証したRCTは見当たらない。** 世に流通している「2週間ルール」に
一次エビデンスは確認できなかった。ただし下限は接触皮膚炎領域のROATデータから導ける。

- 陽性ROATの中央値は3日、**全陽性例が10日以内に出現**。「最低10日間」が必要（Amsler 2022）
- ESCD は約15日を推奨。強く疑う場合は3〜4週まで延長

さらに **複数の活性成分を同時に使うと刺激は加算される**。3週間の累積刺激性試験
（n=35〜37）で、アダパレン併用の累積刺激指数はトレチノイン・タザロテン併用より
有意に低く、後者では中止例も多かった（Dosik 2006）。

→ **2週間は「害が出ないこと」の確認期間**であって、効果の帰属には足りない。
効果まで見るなら上表の時定数まで待つ。この二段構えで運用する。

### レチノイドの刺激は1〜4週がピーク

retinization による刺激は開始1〜2週でピーク、耐性の獲得は概ね4〜8週（Leyden ら）。

→ **4週未満での中止判断をしない**ことを事前にルール化する。
これがないと、効いている処方を刺激期に切ってしまう典型的な脱落パターンに入る。
逆に4〜8週を過ぎても刺激が続くなら、それは本物のシグナル。

## 7. 続けるための設計 — 通知より工程削減

### 実態: 外用のアドヒアランスは想像よりずっと低い

| 事実 | 出典 |
|---|---|
| 皮膚科処方の約1/3は薬局で受け取られてすらいない | Storm 2008, JAAD |
| 乾癬8週試験で 84.6% → 51%、ざ瘡で 85% → 42% に減衰 | Shah 2022 レビュー／Carroll 2004 |
| 外用は内服より不良（外用74.7% vs 全身療法56.3%が不良） | Feldman 2006／Lo 2024 |
| **自己申告は実測の約2倍を報告**（ログ80〜90% vs 隠れ電子モニタ実測40%） | Krejci-Manwaring 2007 |

**脱落は「あるとき突然やめる」ではなく初日から連続的に減衰する。**
だから介入は開始から**2〜6週に集中投下**するのが理にかなう。

### 効く介入の優先順位

| 順 | 介入 | 根拠 |
|---|---|---|
| 1 | **工程を減らす** | 1日1回79% vs 1日2回69%。配合1剤88% vs 別々に塗る61% |
| 2 | **早期のチェックポイント** | 受診前後でアドヒアランスが上がる（white coat compliance）。初回フォローを数日〜数週に置くこと自体が治療戦略（Heaton/Levender/Feldman 2013） |
| 3 | **書面のアクションプラン** | 適切な使用指示を覚えていた患者はわずか4%（Lo 2024） |
| 4 | リマインダー | **条件依存**。日焼け止めには有効（56.1% vs 30.0%, P<.001／Armstrong 2009）だが、ざ瘡外用では無効（Boker 2012、有意差なし） |

**リマインダーが効くのは「想起されにくく、即時のフィードバックがない行動」**（＝日焼け止め）。
すでに意識している治療に通知を足しても上乗せしない。通知を増やす前に、
対象行動がどちらのタイプか見極める。

### 記録は「測定器」ではなく「行動介入」として使う

自己申告は実測の倍を報告するので、継続率の数値としては信用できない。
一方で **記録・観察されている状態そのものが継続を押し上げる**
（Hawthorne効果。Svendsen 2018 では通知＋実測連動アプリで4週時 65% vs 38%, P=0.004）。

通知単独が無効（Boker 2012）で通知＋実測連動が有効（Svendsen 2018）だった対比が重要。
効いているのは「思い出させること」ではなく **「客観的に記録され、見られていること」** の側。

### 「改善したらやめる」への対策

効果を実感した患者ほど中断しやすいという逆説が報告されている（Lo 2024）。
これは意志の問題ではなく構造的なもの。
**開始時点で維持期の目的を明示しておく**（「良くなってからが本番」）。

## 8. 標準化写真のプロトコル

| 項目 | 仕様 | 根拠 |
|---|---|---|
| 頻度 | **4週間隔**（ベースライン／4週／8週／12週） | 皮膚科臨床試験の定型。毎日撮ると日々のノイズに埋もれる |
| レンズ | **望遠側（90〜105mm相当）**。標準・広角は使わない | 50〜55mm相当では顔面中央部に歪みが出る（midface distortion） |
| 角度 | レンズ面を対象に**垂直（90°）**。正面／左45°／右45°の3枚に固定 | JAMA Dermatol 2025 |
| 照明 | **拡散光**（リングライト等）で固定。自然光は使わない | 時刻・天候で変わり、色調の比較が壊れる |
| 位置 | 三脚＋**床のテープマーカー**で距離と立ち位置を物理的に固定 | 再現性を記憶に依存させない |
| 背景 | 無反射・単色を常設。濃い肌色にはロイヤルブルーが色被りしにくい | JAMA Dermatol 2025 |
| 条件 | 同一の前処置（洗顔後◯分・メイクなし）・体位 | 崩れた回のデータは比較から除外する |

**スマートフォンで撮るなら望遠レンズを使い、距離を取ること。** 標準／広角で寄って撮ると、
見ているのは肌の変化ではなくレンズ由来の変形になる。

## 9. この文書の限界

- 本計画は医療行為の代替ではない。脂漏性皮膚炎・肝斑・酒さ等の可能性がある場合は皮膚科受診が必要
- **左目の下の局所的な赤み28は、一度医師に見てもらう価値がある**
- ポテンツァのアフターケアは施術クリニックの指示が常に優先。本書の「5〜7日」は
  複数のクリニックガイドに共通する専門家コンセンサスで、施術強度による個別調整が要る
- 本文中の数値（毛穴41.7%縮小、ブルーライト遮断87.0%等）は**特定の製剤・条件下での報告値**で、
  同じ結果が出ることを保証しない
- §6 の「2週間ルール」は ROAT データとレチノイドの retinization データからの**導出**であって、
  間隔そのものを検証した試験ではない
- MARK-VU の数値は測定条件（洗顔後の経過時間・室温・湿度・機器の接触圧）で変動する。
  特に水分の「none」表示は測定不良の可能性が高い
