# マラソンの栄養・補給・電解質・サプリ・リカバリー — 徹底調査 2026-08-29

対象: 藤井勇成（30歳男性 174cm 74.2kg）／ 直近レース 2026-10-25 横浜マラソン（完走目標・想定5:30〜6:10）
方法: 8領域を並列調査し、各領域に反証側からの検証をかけた。効果が無いもの・害があるものも同じ重みで記載する。

**この文書の使い方**: §1 の5つだけを実行する。それ以外は「知っている」だけでよい。
やらなくてよいことのリスト（§8）は、無駄な出費と手間を止めるためにある。

---

## 1. 結論 — いま効く順に5つ

| 順 | やること | なぜ |
|---|---|---|
| **1** | **血液検査（フェリチン・Hb・25(OH)D）を受ける** | 一度も受けていない。鉄欠乏は男性ランナーでも3〜11%あり、非貧血でも持久力が落ちる。フェリチンを測る前に鉄を飲むと、値が偽って上がって以後の判断材料を永久に失う |
| **2** | **糖質を日別3層にする**（260〜335 / 370〜445 / 520〜670 g） | 市民ランナーは推奨を大きく下回っており、糖質3 g/kg未満の群は5 g/kg超の群より炎症マーカーが高い。「感覚で足りている」は当てにならない |
| **3** | **ロング走11本を「腸のトレーニング」に転用する** | 2週間の反復摂取で消化器症状が47〜63%、糖質吸収不良が45〜54%減る。追加の手間はゼロ |
| **4** | **ジムのカーフレイズを腱プロトコルにする** | 8週で獲得できる組織適応は腱だけ。しかも機械的負荷が主因で、サプリではない |
| **5** | **発汗率を1回測る**（9/21のロング走） | 発汗率0.5〜2.5 L/h、発汗Na 10〜90 mmol/L と個人差が極端で、集団平均から推定できない |

**カフェインだけは例外的に「買ってよいサプリ」**（3〜6 mg/kg・60分前・持久で2〜3%改善）。それ以外はほぼ不要。

## 2. 日常の栄養

### 2-1. 糖質 — 1日いくらではなく、その日の練習量で決める

Burke階層（国際合同声明の中核）を体重74.2kgに換算。

| その日 | g/kg | 糖質 |
|---|---|---|
| 休養日・6km未満（週2日） | 3.5〜4.5 | **260〜335 g** |
| 通常日 6〜10km単発・筋トレのみ（週3日） | 5〜6 | **370〜445 g** |
| **二部練日・ロング走日（週2日）** | 7〜9 | **520〜670 g** |

食品換算: ご飯150g=55g／6枚切食パン1枚=27g／おにぎり1個=39g／うどん1玉=52g／バナナ1本=21g。
通常日なら ご飯4杯(220g)＋食パン2枚(54g)＋バナナ2本(42g)＋果物乳製品(90g) で406g。

W5（週40km）の週平均は約430 g/日（5.8 g/kg）。

**1回だけの答え合わせ**: 8/29から2週間のうち、通常日1日・二部練日1日・休養日1日の計3日だけ、
食べたものを全部写真に撮って糖質gを実測する。常時記録はしない（続かない）。

### 2-2. タンパク質 — 134g を毎日固定、4回に分割

- 合同声明は 1.2〜2.0 g/kg/日。より新しい IAAO 法は 1.83〜2.1 g/kg/日 と高い推定を出すが、
  **IAAO は窒素出納法より30〜40%高く出る系統的バイアスが指摘されており、2.1 は追わない。**
- **1.8 g/kg = 134g を1つの数字として固定する。**範囲にしない。
- **1食あたりの量が独立に効く。** 1回 0.3 g/kg（22g）が下限、20〜40g を3〜5時間おきに4回。
- 内訳例: 朝35g（卵2個12＋納豆1p 8＋ギリシャヨーグルト100g 10＋ご飯）／昼35g（鶏むね150g）／
  夕40g（鮭1切20＋豆腐150g 10＋卵1個6）／補食25g（牛乳400ml 14＋プロテイン10）
- **最も抜けやすいのは朝5時のラン直後。**二部練の日はAM後30〜60分以内に25g以上（プロテイン25g＋バナナ）。
- 「夜にまとめて帳尻合わせ」は、総量が同じでも劣る。

### 2-3. 脂質 — 総エネルギーの20%（62g）を下回らない

低脂肪食は男性のテストステロンを10〜15%低下させる（Whittaker & Wu 2021, 6研究206名）。

### 2-4. 朝5時のランは絶食でよいか

**距離と強度で分岐させる。**

| | 判断 |
|---|---|
| **60分以内・Z1-2 のAMラン（4〜5km）** | **絶食で可** |
| 15km以上のロング走・テンポ・インターバル | **絶食で行わない** |

絶食トレは持久系エリートの38%が実施しているが、**骨傷害の既往と関連している**（Raleigh 2024, EJSS）。
糖質制限は安静時・運動中の骨形成マーカーを低下させる。8週で骨を守りたい今、ここは踏まない。

そして**「運動30〜60分前に糖質を摂るとリバウンド低血糖で失速する」という通説は否定されている**（Jeukendrup 2010）。
5:00スタートなら 4:30 に食べてよい。

### 2-5. 二部練後の急速糖質補給は不要

「1.2 g/kg/h」のプロトコルは**回復時間が8時間未満の場合の話**。
AM05:00 と PM18:30 は13時間半あくので、1日の総糖質が上の帯に入っていれば足りる。

## 3. レース中の補給

### 3-1. 量 — 上限を狙わない

| | |
|---|---|
| 単一糖（ブドウ糖・マルトデキストリン単独）の酸化上限 | **60 g/h**（SGLT1が飽和） |
| グルコース＋フルクトースの酸化上限 | 約90 g/h（報告ピーク105 g/h） |
| **パフォーマンス側の用量反応** | **約40 g/h で実質飽和**（39 g/h と 64 g/h に差なし、Newell 2018） |

**流行の 120 g/h を支えるのは、エリート山岳ランナー26名の単一RCT（Viribay 2020）だけで、
評価項目はレースタイムではなく翌日の回復指標。** 2026年の *Sports Medicine* 批判レビュー
「Fuelled or Fooled?」が「代謝データと現場の採用実態が乖離している」と明言している。

**→ 本番は 55〜65 g/h を 20〜30分刻み、総量 約325g。**

**「自分は遅いから補給は関係ない」は成り立たない。**
5:30ペースは 62% VO2max で、外因性糖質酸化が最大になる **51〜64% 帯のど真ん中**。
むしろ市民ランナーはエリートより補給の恩恵が大きい（効果量は運動時間が長く訓練度が低いほど大きい）。

### 3-2. 腸のトレーニング — ロング走11本に重ねる

2週間の反復摂取で消化器症状 47〜63%減、糖質吸収不良 45〜54%減。

| 本 | 日付 | 試す量 |
|---|---|---|
| 1本目 | 9/1 | 30 g/h |
| 3本目 | 9/7 | 35 g/h |
| 5本目 | 9/13 | 40 g/h |
| 7本目 | 9/21 | 45 g/h |
| 8本目 | 9/25 | 50 g/h |
| 9本目 | 9/30 | 55 g/h |
| 10・11本目 | 10/5・10/10 | **60 g/h（本番と同じ）** |

**1回のボーラスを30gより大きくしない。** 腸内浸透圧負荷が上がり、EIGS（運動誘発性胃腸症候群）の
循環系-消化管経路（内臓低灌流）と重なって症状を誘発する。25g＋水100〜200mlが上限。

### 3-3. 形態

**ジェル ＝ ドリンク ＞ 固形バー。** 同一糖質量でも固形バーは消化器症状を増やし、パワーも落とす
（Guillochon & Rowlands 2017, n=12, 80g/h）。**24km以降で固形（バー・おにぎり・羊羹）を食べない。**

### 3-4. カーボローディングは1日で終わる

Bussau 2002: 不活動＋10 g/kg で **24時間** で最大グリコーゲン（95→180 mmol/kg）に到達。
**古典的な「3日間の枯渇期＋3日間の高糖質」は不要で有害。**
体重が1.0〜1.5kg増えるが、それはグリコーゲンと結合水であり正常。

## 4. 水分と電解質

### 4-1. 脅威は脱水ではなく飲みすぎ

**運動関連低ナトリウム血症（EAH）はマラソン完走者の10〜15%に生じる**（Almond 2005 NEJM, n=488で13%）。
**4時間超の完走者・遅いランナー・体重が増えたランナーに強く集中する。**
藤井さんは想定5:30〜6:10 で、この層のど真ん中に入る（体重74.2kg・男性という点は保護的）。

一方「2%脱水でパフォーマンスが落ちる」という定説は、**ブラインド条件・実走条件では一貫して再現されない**
（Wall 2015 は −3%まで差なし）。実際のマラソンでは**速いランナーほど体重を落としている**（Zouhal 2011, n=643）。

### 4-2. 運用ルールは3つだけ

1. **喉が渇いていなければ、その給水所は飛ばす。** 特に前半20kmのフラット区間
2. **1つの給水所で2杯以上取らない。**（横浜は給水所18か所。約19分に1回・平均2.3kmごと。
   1杯150ml×18 = 2.7L = 470ml/h が上限側の目安。2杯取ると 900〜1400ml/h で EAH 領域）
3. **飲むのは水ではなくスポーツドリンク。** 無ナトリウム水のみだと血漿Naは確実に下がる。
   ただし Na 21 mEq/L 程度で十分で、それ以上濃くしても差は出ない

**目標は「レース前 74.2kg → ゴール 72.0〜73.5kg（−1〜−3%）」。**
体重が増えていたら、その時点で飲みすぎ。**当日朝とゴール後に必ず測る。**

### 4-3. 塩タブレットは要らない

**ナトリウム補給はEAHもけいれんも脱水も嘔気も予防しない**（Hoffman & Stuempfle 2015/2016）。
EAHを決めるのはナトリウム量ではなく**水の量**。
筋けいれん（EAMC）の原因も電解質ではなく**筋疲労による脊髄反射の異常**（Schwellnus）で、
前向きコホート4件で血清電解質異常との関連は否定されている。

### 4-4. 発汗率を測る（まだ一度もやっていない）

発汗率 0.5〜2.5 L/h、発汗Na 10〜90 mmol/L と個人差が極端で、**集団平均から個人を推定できない。**

```
走る直前に裸で体重 → 1時間走る → 汗を拭いて裸で体重
発汗率(L/h) = (前 − 後 + 飲んだ量kg)
```

**9/21 のロング走（15.8km）で1回測る。** これが給水計画の唯一の土台になる。

## 5. サプリメント

### 5-1. 効くもの（買ってよい）

| | 用量 | 根拠 |
|---|---|---|
| **カフェイン** | 3〜6 mg/kg（222〜445mg）・60分前 | 持久で2〜3%改善。**唯一「効くことが確実」なサプリ** |
| **鉄**（検査で欠乏なら） | 隔日・単回・朝 | 非貧血の鉄欠乏でも持久力が落ちる。**連日投与は hepcidin を上げて自分で吸収を潰す**（Stoffel 2017） |
| **ビタミンD**（検査で欠乏なら） | 〜4,000 IU/日まで | 日本人成人の不足は9割。ただし**欠乏している人にしか効かない** |

**カフェインの注意2点**: ①レース前の「カフェイン抜き」は不要（習慣摂取で効果はほぼ減弱しない、
Carvalho 2022, 60研究のメタ解析）。②**PM18:30のセッション前には摂らない** —
就寝6時間前の400mgで総睡眠時間が1時間以上減る（Drake 2013）。睡眠が既に7%しか測れていない今、これは致命的。

### 5-2. 条件つき

**コラーゲン／ゼラチン＋ビタミンC** — 血中のコラーゲン合成マーカーは倍になるが、
**安定同位体＋筋生検で直接測ると、結合組織のタンパク合成は上がっていない。**反対側の証拠が強い。

→ **8週で腱を強くする主因は機械的負荷であり、サプリではない。**
5,000円超の「腱サプリ」「特許コラーゲンペプチド」は買わない。カーフレイズをやる。

### 5-3. 効かない／有害（買わない）

| | 理由 |
|---|---|
| 重曹 | 効果窓が30秒〜12分。マラソンには原理的に適用外。高確率で下痢 |
| ベータアラニン | 同上。10分超の運動でコンセンサスなし |
| クレアチン | 0.5〜1.5kgの水分性体重増が走行の代謝コストを直接押し上げる。**8週間は特に不可** |
| 硝酸塩（ビートルート） | 訓練度が上がるほど効果が消える。5:30ペースでは優先度が低い |
| HMB・BCAA・EAA・グルタミン・ZMA・アルギニン・シトルリン | AIS Group C（効果未証明） |
| **高用量抗酸化（ビタミンC 1000mg＋E 235mg）** | **ミトコンドリア生合成を阻害する**（Paulsen 2014, n=54, 11週: COX4とPGC-1αの増加が減弱） |
| タルトチェリーの常用 | 同じ適応阻害の論理。使うなら**レース前後8日間だけ** |
| プロバイオティクス | 運動中の消化器症状への証拠はわずか |
| 塩タブレット | §4-3 |
| ハイドロゲル（Maurten等） | 胃排出は速まるが外因性糖質酸化は変わらない |
| CYP1A2 遺伝子検査 | 陽性研究と陰性研究が拮抗。費用に見合う判断材料が出ない |
| 市販の発汗パッチ検査 | 測っても処方が変わらない |
| メラトニンの個人輸入 | 日本では「専ら医薬品」で薬機法違反。かつ睡眠問題の原因は手首の痒みであって内因性ではない |

**そして品質の問題**: サプリの9〜15%が禁止物質・未表示医薬品成分に汚染されている。
「プレワークアウト」「燃焼系」「プロプライエタリブレンド（成分量非開示）」に汚染報告が集中している。

## 6. リカバリー

### 6-1. 一貫して効くのは2つだけ

**睡眠と、栄養の総量。** それ以外は「主観的に効いた感じがする」止まり。

### 6-2. ★アイスバスは、いま使ってはいけない

**冷水浸漬は筋トレ後に使うと筋肥大と筋タンパク合成を実測できるレベルで阻害する。**
Roberts 2015: 12週で大腿四頭筋量の増加が **+15% → +2%**。獲得を直接捨てることになる。

持久系の適応（VO2max・TT）は阻害されないが、**パフォーマンス回復への効果量は g=0.19 と trivial**。
そして急性の「効いた感じ」は、**同じ手順の温水浸漬（プラセボ）と区別できない。**

→ **使ってよいのは「適応がもう要らない局面」＝レース後だけ。** 用量は 11〜15℃ × 11〜15分。

### 6-3. 効かないもの

| | |
|---|---|
| ストレッチ（筋肉痛予防目的） | Cochrane 2011, 12RCT n=2377。100点尺度で約1点。**臨床的に無意味** |
| フォームローラー（運動後） | 後ローリングの効果は軽微。前ローリングなら柔軟性 g=0.34 で意味がある |
| マッサージ | 筋肉痛と主観的疲労には効くが、筋力・跳躍・持久のパフォーマンス回復は改善しない |
| 空気圧マッサージブーツ（NormaTec等） | 加圧ウェアを上回る証拠がない。同じ金額を血液検査と睡眠計測に回す |
| アクティブリカバリー | 乳酸除去は速いが、翌日以降の回復は完全休養と変わらない |
| **「運動後30分のアナボリックウィンドウ」** | **総タンパク質量を統制すると消える**（p=0.18/0.49）。支配変数はタイミングではなく1日の総量 |
| サウナ・熱い風呂を「回復手段」として使う | エビデンスは暑熱順化・血漿量増加であって回復ではない |

**加圧ウェア（コンプレッションタイツ）だけは、実証されている中で最も費用対効果が高い「害のない」手段。**

### 6-4. ★下り対策 — 唯一強い証拠がある手段

**「事前に一度下りを走っておく」（repeated bout effect）。CKは約半減、筋力低下も有意に軽減。**

- **勾配は −3〜−5% で足りる。** 横浜の最大高低差は30m。−8〜−10% は過剰で、事前ダメージのほうが害になる
- 防御効果は **3〜6週持続**する
- **レース前14日以内に新規の下り走を入れない。**間に合わない上、当日に筋損傷を持ち込む
- ロング走の直前48時間・直後72時間に下り走を置かない

→ 計画の **9/17・9/25・10/5** の3本がこれに当たる。10/5 がレース20日前で、防御効果の窓に入る。

**そして、下り走で生じた筋損傷を事後に速く治す手段は実質的に存在しない。** 回復は約4日かかる。

### 6-5. 睡眠が取れない場合

**仮眠は部分的睡眠不足に対する実証された代替。** 用量は 20〜90分・13〜16時。
ただし **二部練の日に90分の仮眠は取らない**（夜間睡眠を壊す）。20〜30分に留める。

| いつ | 何を |
|---|---|

| **前日（10/24）** | 糖質 10 g/kg = **742g**（1日で完了する。枯渇期は作らない）。低残渣・低脂肪・低食物繊維で。体重が1.0〜1.5kg増えるのは正常 |

| **60分前** | カフェイン 3〜6 mg/kg（222〜445mg）。※過去に試した量で |

運動誘発性の小腸傷害とバリア破綻を悪化させ（van Wijck 2012）、腎プロスタグランジンを介して
自由水排泄を抑えるため EAH リスクも上げる。

## 8. やらなくてよいこと（費用と手間を止めるため）

## 11. 体内で何が起きるか — 8週で獲得できるもの / できないもの

**持久トレーニングの適応は「時定数の異なる複数の時計」が同時に走っている現象。**
8週という窓では心肺・代謝系はほぼ完成するが、**腱と骨はまったく間に合わない。**

| 組織・系 | 時定数 | 8週で | 備考 |
|---|---|---|---|
| **血漿量** | 数日〜2週で +5〜11% | ◎ ほぼ完成 | **止めると2日で落ち始める** |
| **ミトコンドリア** | 半減期6〜8日。6週で獲得可能分のほぼ全部 | ◎ | 量は総走行量、機能は強度が決める |
| **毛細血管** | 4週で +13%、以後横ばい | ◎ | **低強度だけでは伸びにくい** |
| 脂質酸化 | 4週 | ◎ | |
| 筋線維 IIx→IIa | 数週 | ◎ | 完全に可逆。止めるとIIxが元より増える |
| 消化管耐性 | 2〜4週 | ◎ | §3-2 の腸トレ |
| 走効率 | 6〜14週で +2〜5% | △ 部分的 | |
| ヘモグロビン質量 | 6週〜9か月で +5〜10% | △ +1〜3%程度 | **今回の主戦力にならない** |
| **腱スティフネス** | **12週以上** | **✕ 不可** | ランニングだけでは硬くならない |
| **骨** | **リモデリング周期 3〜4か月** | **✕ 不可** | 下記 ★ |
| 左室の拡大（スポーツ心臓） | 6〜12か月 | ✕ | **サブスリーの律速はここ** |

### ★ 骨の脆弱窓 — 9/19〜10/24 が最長走とちょうど重なる

**負荷を上げた最初の3〜8週は、破骨細胞の吸収が先行して骨が一時的に弱くなる。**
藤井さんの窓は **2026-09-19 〜 2026-10-24**。ロング走のピーク（10/5・10/10）が窓の末尾に重なる。

**対策はひとつだけ**: この期間に「体調が良いから」という理由で +10% を超えて伸ばさない。
**骨の吸収相は自覚症状を出さない。**痛みが出た時にはもう遅い。

そして疲労骨折をやると復帰に **8〜24週**。8週で得た心肺適応を全部失う。

### レース後に完全に止めない

**2週間でミトコンドリア含量の獲得分の約8割が消える。** 3週で9割弱。
**過去2回の中断は、まさにここで起きている。**
横浜後の処方は「完全停止」ではなく、量を大きく落として頻度だけ残す形にする。

そして **サブスリーの律速である心臓のリモデリングは1年かかる。**
横浜後の11か月がそのまま持ち時間なので、**レース後に3か月中断すると2027年秋の目標が生理学的に成立しなくなる。**

### 血液検査の期限は「今」

**鉄が不足していた場合の是正には6〜8週かかる。** 10/25 に間に合わせるなら、いまが最終期限。

## 12. トレーニング方法 — 8週の費用対効果

### ★ 計画の修正2点

**① ロング走 23.1km は長すぎる。**
ロング走は距離ではなく**時間**で上限を見るべきで、実務上限は **2:30〜3:00**（Daniels）。
23.1km は 8'30"/km で **3:16** となり超過する。

| 距離 | 8'30"/km | 判定 |
|---|---|---|
| 23.1 km | 3:16 | ★超過 |
| **21.5 km** | **3:03** | 上限域 |
| 21.1 km | 2:59 | 上限内 |

→ **最終ロング走を 21.5km（10/10）に下げる。**
21.1km を超えるのでレース当日の跳躍は HRR 2.28帯 → 1.52帯 に落ち、かつ3時間の上限に収まる。

**35km以上の練習走は不要。** 傷害オッズ比は1.01でリスクは上がらないが、
**完走タイムへの追加利得も認められない**（Fokkema 2020, n=441）。

**② テーパーの削減幅が足りない。**
Bosquet 2007（27研究のメタ解析）の最適解は **「2週間・量を41〜60%削減・強度と頻度は維持」**。
W7 37km に対して W8 26km（−30%）では削減不足。**20km 前後へ下げる。**
**頻度と強度は落とさない。**落とすのは量だけ。

### durability（疲労下で閾値が落ちない能力）

Jones 2024 以降「第4の決定因子」として確立しつつある概念。マラソン成績との相関が強い。

**市民ランナーは90分の低強度走を1本走るだけで閾値速度が5〜6%落ちる。**
つまり横浜は「フル通して閾値が落ち続ける」レースになる。

**そして durability を鍛える最も直接的な手段は筋トレ。**
筋トレの追加は「疲労した後のランニングエコノミー」と「疲労後の高強度持続力」を劇的に改善する。
ジムに行けていることは、この8週間で最大の資産になる。

### 8週の費用対効果ランキング

1. **レース中の糖質補給**（5時間半では補給不足がそのまま関門落ちに直結する）
2. **腸のトレーニング**（2週で GI症状 44〜49%減。6〜8週で 45→90 g/h）
3. **テーパーの規律**（Bosquet 2007。規律の有無が市民ランナーでは特に効く）
4. 筋トレ（durability）
5. 下り対策の反復ボウト効果

**上位3つは合計でほぼゼロ円・低リスク**でありながら、下位の介入より大きい。

### やらないこと（トレーニング編）

| | 理由 |
|---|---|
| **カーボンプレートシューズを買う** | 効果は速度依存で 6:00/km で0.9%。**7'50〜8'45/km のデータは存在しない。**約20%が非反応者で、舟状骨疲労骨折の報告もある |
| ケイデンス改造（エコノミー目的） | 好みの108%へ上げると代謝コストが約6.5%増える報告。**膝の負荷は下がるがエコノミーは改善しない** |
| プライオメトリクス（エコノミー目的） | 効果は12km/h以上で確認。**10km/h では有意差なし** |
| 独立したMP走 | 目標ペース 7'50〜8'45/km が現在のイージーペースとほぼ同じ強度帯で、特異性練習として成立しない |
| ノルウェー式ダブルスレッショルド | 実証は Ingebrigtsen 三兄弟（n=3・血縁）の観察研究のみ |
| fasted long run | 6週間の介入で絶食群と補給群の VO2max・TT の伸びが同等（+9%／+8%） |
| 上り坂インターバルを独立セッションに | 根拠は中距離の16〜20歳（n=40）。完走目的の8週では優先度が低い |
| 高地トレーニング・低酸素テント・高地マスク | 海抜8週でヘモグロビン質量は +1〜3% しか動かない |
| 唾液テストステロン/コルチゾール比の監視 | 診断的妥当性が確立していない |
| 「オープンウィンドウ」前提の練習間引きと免疫サプリ | 仮説自体が近年強く批判されている |
| **テーパー期に筋トレをゼロにする** | 量は半減してよいが**重量は維持**。完全停止は疲労下エコノミーの獲得を失う |
| **10/12以降に新規の下り刺激を入れる** | 反復ボウト効果はレース14日前までに完了させる。直前は筋損傷を残すだけ |

## 付録: 調査の範囲と限界

- 8領域のうち7領域（日常の栄養／レース中の補給／水分と電解質／サプリ／リカバリー／体内の適応／トレーニング方法）を調査・記載した
- 残る「レース当日の実務」は §7 に、既出エビデンスと他領域の所見から構成してある
- **5:30〜6:10 の市民ランナーに対する補給の直接エビデンスは存在しない。**
  用量反応研究はすべて1〜3時間・訓練済み〜エリート・自転車中心である。ここは外挿である
- 練習で再現できるのは最長3時間まで。**3〜5.5時間の補給耐性は、原理的に未検証のまま本番を迎える**
