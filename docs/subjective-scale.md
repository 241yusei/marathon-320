# 走る準備度・脚の張りの基準（2026-09-06 制定）

本人から「基準は？」と聞かれて、**定義せずに数字を求めていたことに気づいた**ので決めた。
毎朝20秒で答えられる粒度にする。厳密さより再現性を優先する。

## 走る準備度（0〜10）

**問い: 「いまから走ってこい」と言われたら、どれくらい素直に行けるか。**
体調そのものではなく、**行動に移せる度合い**を答える。

| 点 | 状態 |
|---|---|
| 0〜2 | 走る気が起きない／体が重くて無理 |
| 3〜4 | 行けなくはないが、かなり気が進まない |
| **5〜6** | **普通。言われれば行く** |
| 7〜8 | 走りたい。体が軽い |
| 9〜10 | 絶好調。長く行けそう |

## 脚の張り（0〜10）

**問い: 脚の筋肉の張り・重だるさはどれくらいか。★痛みではない。**

| 点 | 状態 |
|---|---|
| 0〜2 | 張りなし |
| 3〜4 | 少し重い |
| **5〜6** | **はっきり張っている。走れるが感じる** |
| 7〜8 | 強い張り。走ると気になる |
| 9〜10 | 走れないレベル |

## ★ 張りと「止める痛み」は別枠。混同しない

上の 0〜10 は**筋肉の張り**の話で、次の2つは**まったく別のもの**である。
0〜10 で答えるものではなく、**あるかないかを即報告する**。

| 何 | どう確かめる |
|---|---|
| **局所的な圧痛** | 脛や足の**1点**を指で押して痛いか |
| **片脚ホップ痛** | その脚だけで跳ねて痛いか |

どちらも**疲労骨折の前駆症状**で、様子見の対象ではない。出たらその場で走るのをやめる。
9/26〜10/31 は骨の脆弱窓（負荷を上げ始めて3〜8週）に当たるので、この期間は特に。

「脚の張りが8」は走ってよい。「圧痛がある」は走ってはいけない。**この差が重要。**

## なぜこの2つだけなのか

主観申告は客観指標より**速く正確にオーバーリーチングを拾う**（3日で判別できる）。
一方で項目を増やすと答えなくなる。Hooper index も RESTQ-Sport も使わない。
**2項目・数字だけ・20秒**を守る。

聞くのは**週2回まで**。毎朝並べると、答えない日が続いたときに読み飛ばす画面になる。
